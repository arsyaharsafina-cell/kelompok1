Teori Singkat: Media Transmisi & Telekomunikasi Dasar

1 Jenis Media Transmisi Kabel (Guided Media)

UTP Straight-Through (T568B – T568B)

Digunakan untuk menghubungkan perangkat berbeda jenis (MDI ke MDIX), seperti PC ke Switch atau Router ke Switch. Susunan pin 1, 2, 3, 6 pada kedua ujung identik.

UTP Cross-Over (T568A – T568B)

Digunakan untuk menghubungkan perangkat sejenis (MDI ke MDI atau MDIX ke MDIX), seperti PC ke PC atau Switch ke Switch (tanpa Auto-MDIX). Pin TX (1,2) disilangkan ke pin RX (3,6).

Kabel Coaxial (RG-6 / RG-58)

Memiliki inti konduktor tembaga tunggal dengan pelindung anyaman logam (braided shield). Jarak jangkau hingga 500 meter (10Base5), lebih tahan EMI dibanding UTP, menggunakan konektor BNC/F-Type.

Fiber Optik (Single-Mode & Multi-Mode)

Mentransmisikan data berupa pulsa cahaya laser/LED melalui inti kaca silika. Single-Mode (core 9µm) menjangkau puluhan kilometer, bandwidth sangat tinggi, dan 100% kebal terhadap interferensi EMI.

Karakteristik Sinyal Listrik vs Sinyal Optik

Pada kabel tembaga (UTP & Coaxial), bit biner 1 dan 0 direpresentasikan sebagai perubahan tegangan listrik (misal +2.5V dan 0V). Sinyal ini mengalami hambatan resistansi tembaga sehingga melemah pada jarak jauh (attenuation) serta mudah terdistorsi medan elektromagnetik (EMI/Crosstalk). Sebaliknya, Fiber Optik mengubah bit menjadi kedipan cahaya laser (ON = 1, OFF = 0) melalui pemantulan internal sempurna sehingga bebas dari induksi listrik.

Instruksi Praktikum Lab Maya TJKT

Lakukan 4 skenario percobaan berikut secara berurutan pada simulator untuk memahami perilaku Lapisan Fisik (Physical Layer):

Percobaan 1: Koneksi Perangkat Berbeda Jenis (Straight-Through)

Atur Node A = PC / Workstation, Node B = Switch Layer 2, Kabel = UTP Straight-Through, Jarak = 50 m, Auto-MDIX = OFF, EMI = Rendah. Klik Uji & Kirim Paket. Amati jalannya bit dan hasil pada Osiloskop.

Percobaan 2: Koneksi Perangkat Sejenis & Pengujian Cross-Over

Ubah Node A = PC dan Node B = PC dengan kabel UTP Straight-Through (Auto-MDIX OFF). Amati kegagalan pinout TX-to-TX pada log. Kemudian ganti kabel menjadi UTP Cross-Over dan uji kembali.

Percobaan 3: Pengaruh Jarak (Attenuation) & Interferensi EMI

Hubungkan PC ke Switch menggunakan UTP Straight-Through, lalu naikkan slider Jarak Kabel menjadi 180 meter dan ubah EMI menjadi Tinggi. Perhatikan kerusakan bit (Bit Error Rate) pada kolom kanan.

Percobaan 4: Solusi Jarak Jauh & Bebas EMI dengan Fiber Optik

Atur Node A = OLT / Media Converter, Node B = ONT / Media Converter, Media = Fiber Optik Single-Mode, Jarak = 850 meter, EMI = Tinggi. Bandingkan stabilitas sinyalnya dengan kabel tembaga!
